# مشروع زمردة

## التشغيل
افتح `index.html` عبر سيرفر محلي (مفضل) أو ارفعه كما هو إلى الاستضافة.

## الملفات
- `index.html` — واجهة المتجر.
- `admin.html` — لوحة إدارة المنتجات التجريبية.
- `css/style.css` — تصميم المتجر.
- `css/admin.css` — تصميم لوحة الإدارة.
- `js/products.js` — المنتجات الافتراضية.
- `js/app.js` — وظائف المتجر والبحث والفلاتر وGift Finder والطلب وواتساب.
- `js/admin.js` — إضافة/تعديل/حذف المنتجات عبر LocalStorage.
- `assets/images/` — مكان الصور المحلية مستقبلاً.
- `assets/icons/` — مكان الأيقونات المحلية مستقبلاً.

## ملاحظة مهمة عن الإدارة
لوحة `admin.html` الحالية تجريبية وتخزن المنتجات في LocalStorage على جهاز/متصفح المستخدم. هذا لا يُعتبر نظام إدارة آمن ولا يصلح لإدارة متجر حقيقي من عدة أجهزة. للإنتاج نحتاج Backend وقاعدة بيانات وتوثيق دخول.

## الطلب
الزر لا يفتح واتساب مباشرة. يبدأ بنموذج بيانات، ثم شاشة مراجعة، ثم يفتح واتساب مع رسالة الطلب.

## الصور
صور الديمو مستخدمة كرابط مباشر من Unsplash. قبل الاستخدام التجاري النهائي راجع شروط وترخيص كل صورة أو استبدلها بصور تملك حق استخدامها.
